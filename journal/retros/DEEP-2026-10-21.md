## Reopen-test recompute (one-liner)

```
python3 -c "
import json
R=[json.loads(l) for l in open('journal/forecasts.jsonl') if l.strip()]
n=s=0
for r in R:
  if r['status'] not in('won','lost') or r['category']!='say-the-word' or r['ts']<'2026-10-01': continue
  b,a,m=r.get('best_bid_at_record'),r.get('best_ask_at_record'),r.get('market_prob_at_record')
  if b is None or a is None or m is None or a-b>0.06: continue
  Y=r['outcome']=='Yes'; p=r['est_prob'] if Y else 1-r['est_prob']; q=m if Y else 1-m
  if p-q<0.05: continue
  y=1.0 if r['outcome_won']=='Yes' else 0.0; n+=1; s+=(p-y)**2-(q-y)**2
print(n,round(s,3))"
```
